## Two paths, one crossing

The archive and ferryman branches converge on the **same** crossing thought.
The optional connection returns to the starting idea. Neither convergence nor a
cycle requires copying the destination's content.

The `reveals` connection has custom wording and inherits its arrow from
`precedes`. The clue uses a reusable node class; the ferryman uses inline CSS.
The live viewer and copyable code below consume the same source file.
