Lensmap is a text-first mind map with a spatial magnification lens.
Write your thoughts in a small YAML document, with Markdown inside them.
The viewer creates the circles and connections.

Start with [the quick start](./getting-started/), or explore the
[examples](./examples/). The current npm cohort is **0.3.0**.
The `version: v1` authoring format is still experimental.
